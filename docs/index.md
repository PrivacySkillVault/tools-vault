# Security Tools

<div id="psv-tools-app"></div>

!!! info "Privacy-first by default"
    Indicator extraction, text decoding, regular expressions, JSON formatting, timestamp conversion, report drafting, and scoring calculations run in your browser. These tools do not send pasted text to a Privacy Skill Vault server. Threat-intelligence provider links are external and open only when you select them.

!!! warning "Operational use"
    These tools are analyst aids, not substitutes for validated production detections or organizational incident procedures. Validate generated queries and rules in a safe test environment. The threat-intelligence hub opens public provider pages instead of calling authenticated APIs from the browser, avoiding secret API keys in public client-side code.
